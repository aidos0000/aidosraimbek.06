4.3.FTP (File Transfer Protocol):

                                                                                                                              4.3.FTP (File Transfer Protocol):

FTP (File Transfer Protocol) — бұл компьютерлік жүйелер арасында файлдарды беру және алу үшін қолданылатын желілік хаттама. FTP екі компьютер арасында деректерді, әдетте файлдарды, тасымалдау үшін пайдаланылады. FTP — ұзақ уақыт бойы желіде файлдарды беру үшін ең кең таралған стандартты хаттама болып келді.

FTP жұмыс принципі:

FTP клиент-сервер архитектурасына негізделеді, яғни екі құрылғы арасында файлдарды тасымалдау үшін бір құрылғы сервер, екіншісі клиент ретінде әрекет етеді. Клиент FTP серверіне қосылып, файлдарды жүктей алады (download) немесе жібере алады (upload).

FTP жұмыс істегенде клиент мен сервер арасында екі байланыс орнатылады:

  1. Басқару байланысы: Клиент пен сервер арасында байланыс орнатып, командалар мен жауаптар алмасады. Бұл байланыс тұрақты болады.

  2. Деректер байланысы: Файлдар мен мәліметтерді тасымалдау үшін деректер байланысы орнатылады. Бұл байланыс әрбір файлды жүктеу немесе жіберу үшін құрылуы мүмкін.

FTP байланысының құрылымы:

FTP байланысы екі түрлі режимде жұмыс істей алады:

  1. Active (активті) режим:

    • Активті режимде клиент серверге деректер байланысын орнату үшін өз портына серверді шақырады.

    • Клиент сыртқы байланыс орнатып, сервер оған қосылады.

  2. Passive (пассивті) режим:

    • Пассивті режимде сервер өзінің деректер портын ашады, ал клиент осы портқа қосылып деректерді алады.

    • Бұл режим, әсіресе, клиенттің NAT немесе брандмауэр арқылы қорғалған желіде болғанда тиімді, себебі серверге қосылу оңайырақ болады.

FTP командалары мен жауаптар:

FTP серверіне әртүрлі командалар жіберіледі, олар файлдарды алу, жіберу, каталогтарды көрсету және т.б. әрекеттерді орындауға мүмкіндік береді. Әрбір командаға сервер жауап қайтарады, оның ішінде операцияның сәтті орындалуы немесе қателік туралы мәліметтер бар.

FTP командаларының мысалдары:

  1. USER — серверге пайдаланушының атын енгізу.

    • Мысалы: USER username

  2. PASS — пайдаланушының құпия сөзін енгізу.

    • Мысалы: PASS password

  3. LIST — сервердегі каталогтарды көрсету.

    • Мысалы: LIST

  4. RETR — файлды серверден жүктеу.

    • Мысалы: RETR filename

  5. STOR — файлды серверге жүктеу.

    • Мысалы: STOR filename

  6. QUIT — FTP сеансын аяқтау.

    • Мысалы: QUIT

FTP жауап кодтары:

FTP сервері әрбір командаға жауап ретінде үш таңбалы код жібереді. Бұл кодтар сервердің сұрауға қалай жауап бергенін көрсетеді:

  1. 1xx — ақпараттық жауап (мысалы, байланыс орнатылды).

  2. 2xx — сәтті жауап (мысалы, файл табылды немесе әрекет сәтті орындалды).

  3. 3xx — қосымша әрекет қажет.

  4. 4xx — уақытша қате.

  5. 5xx — тұрақты қате.

Мысал:

  • 200 OK — сұрау сәтті орындалды.

  • 550 File not found — файл табылмады.

FTP артықшылықтары:

  1. Жоғары жылдамдық: FTP үлкен файлдарды салыстырмалы түрде жылдам тасымалдауға мүмкіндік береді.

  2. Қарапайымдылық: FTP протоколы қарапайым және оны көптеген операциялық жүйелер мен құрылғылар қолдайды.

  3. Үлкен файлдарды тасымалдау мүмкіндігі: FTP үлкен деректер көлемін тасымалдау үшін тиімді.

FTP кемшіліктері:

  1. Қауіпсіздік мәселелері: FTP деректерді шифрламайды, сондықтан жіберілетін деректер (соның ішінде құпия сөздер) ұрлануы немесе өзгертілуі мүмкін. Осы себептен құпия ақпаратты тасымалдау үшін FTPS немесе SFTP сияқты қауіпсіз нұсқалары пайдаланылады.

  2. Желілік брандмауэрлермен қиындықтар: FTP активті режимде жұмыс істегенде брандмауэрлер немесе NAT құрылғылары арқылы байланыс орнату қиын болуы мүмкін.

  3. Қосылымды басқару: FTP қосылымдарын дұрыс басқармау жүйені асыра жүктеп немесе сұраулардың кешігуіне әкелуі мүмкін.

FTPS және SFTP:

FTP қауіпсіздік тұрғысынан бірқатар кемшіліктерге ие. Осы мәселелерді шешу үшін екі негізгі протокол бар:

  1. FTPS (FTP Secure): Бұл FTP-дің қауіпсіз нұсқасы, ол деректерді TLS немесе SSL арқылы шифрлайды.

  2. SFTP (SSH File Transfer Protocol): Бұл FTP-дің SSH арқылы шифрланған нұсқасы, яғни SSH байланысы арқылы қауіпсіз тасымалдауды қамтамасыз етеді. FTPS-тан айырмашылығы, SFTP FTP протоколынан мүлдем басқа және әдетте SSH арнасында жұмыс істейді.

FTP қолдану салалары:

  1. Файлдарды серверге жүктеу/қабылдау:

    • FTP веб-сайтты құру кезінде немесе үлкен деректерді серверге немесе серверден жүктеу кезінде жиі қолданылады.

  2. Құжаттарды және медиа файлдарын тасымалдау:

    • Үлкен бейнемазмұндарды немесе мәліметтер базасын тасымалдау үшін FTP қолданылуы мүмкін.

  3. Резервтік көшірмелерді жасау:

    • FTP көптеген ұйымдарда резервтік көшірмелер жасау үшін қолданылады, себебі FTP сервері файлдарды автоматты түрде сақтауға мүмкіндік береді.

FTP және оның қолданылуы:

FTP көптеген қосымшаларда және ұйымдарда маңызды құрал болып табылады, себебі ол файлдарды жоғары жылдамдықпен және тиімді тасымалдауға мүмкіндік береді. Дегенмен, қауіпсіздік мәселелерін ескере отырып, FTPS немесе SFTP сияқты қауіпсіз нұсқалар пайдалану ұсынылады.

Қорытынды:

FTP — бұл файлдарды сервер мен клиент арасында тасымалдаудың негізгі хаттамасы. Ол қарапайым, жылдам және тиімді, бірақ қауіпсіздік тұрғысынан кейбір кемшіліктерге ие. FTP-ні қауіпсіз пайдалану үшін FTPS немесе SFTP сияқты қауіпсіз хаттамалар қолданған жөн.
